# 原图气泡标注

压缩弹簧主要参数与原图气泡共用12项显示编号。压并高度位于高级参数首行，缺值时可直接补填。标准号、通用精度等级和压并高度均不占用气泡编号。气泡用于查找原图证据；底部同时显示原图识别值和当前参数值，二者可能不同。默认值和公式值没有原图直接证据时不自动放置气泡；其他无可靠位置的参数也可人工定位。标注操作不修改参数值或确认状态。

## 使用

引线连接原图证据锚点与气泡圆周，不穿过编号。气泡半径仍为15个屏幕像素，缩放、平移及拖动后重新计算引线终点；锚点在圆内时不绘制引线。此显示调整不改变气泡位置或标注修订号，也不触发保存。

普通查看模式隐藏原图文字上的小定位圆点，即使悬停或选中气泡也不显示；编号气泡和引线仍显示。进入“调整标注”或人工定位模式时显示定位圆点，结束调整后再次隐藏。仅改变圆点可见性，坐标和内部SVG元素保留，气泡定位、缩放旋转及历史位置计算不变，不修改接口、数据或修订号。前端版本为`20261110-preview-controls`。

打开原图工作台后，可切换原图页码、显示或隐藏标注，沿用适应窗口、缩放与拖动查看。参数名称旁的编号按钮会切换到证据所在页并将位置移到视口中央；普通查看模式点击气泡，或聚焦气泡后按 Enter/空格，会打开“参数”视图并聚焦对应参数行。编号2对应线径；标准号和通用精度相关定位入口打开参数页的标准化设置，原图数据和证据保留。

选择“调整标注”后可拖动气泡；键盘聚焦气泡后方向键每次移动5个屏幕像素。拖动和方向键只移动气泡，证据锚点保留原位。“人工定位”或选中气泡后的“重新定位”允许点击当前页原图设置锚点；Esc取消待定位状态。

位置调整自动保存，界面显示保存中、已保存或失败重试状态。加载失败需点击“重试加载标注”；不会自动反复请求。断网或保存失败时，待保存位置保留在当前浏览器会话内，可点击“保存失败·重试保存”。本地缓存不跨页面刷新；未保存时离开页面会触发浏览器提示。

收到409位置冲突时，可选“使用服务器位置”放弃待保存位置，或“保留本地位置”以服务器最新标注版本重新提交。本地位置只可应用于相同原图；`source_document_id`变化时须使用新原图重新定位。

| 1 | 材料 | 5 | 中径 | 9 | 表面粗糙度 Ra |

显示编号由前端按字段映射，参数列表、气泡文字、详情、未定位清单和键盘提示统一使用；不直接展示历史标注的number。接口和历史标注文档保留原编号、标准号及压并高度记录，所有操作仍按annotation_id/field和location_id关联。旧缓存加载后立即采用新显示编号，不写回标注、不增加任何修订，不重新识别或补定位。

缺少原图位置时不虚构气泡；稀疏页仍使用对应参数编号，例如只有自由长度和粗糙度时显示6和9。标准号、通用精度等级和压并高度从气泡、未定位清单和定位诊断中隐藏，已保存的锚点及人工位置保留在原数据中。压并高度的参数定位会展开高级参数并聚焦其输入行。

## 定位与范围

先读取PDF文本，并复用具有已知输入图像尺寸和方向的OCR坐标。多边形优先还原文字框；只有中心坐标时先转换为左上角。显示坐标包含EXIF旋转与镜像，方向不明的旧OCR坐标不直接复用。原文件及预览地址不改写。

定位依次使用可追溯的字段候选位置、同一文字行/相邻表格单元中的名称与数值，以及原字段候选支持的页面内唯一数字。材料使用目录牌号匹配；端面研磨与研磨粉尘、并紧与不并紧分别判断。多个明确等价的原图位置可显示同号气泡，存在歧义时保留未定位状态。公式、默认值没有直接原图依据时不虚构位置。

仍有缺项时，按显示方向规范化图像后执行一次本地整页补定位及每页最多一轮局部放大/旋转OCR（每轮最多12个裁剪输入，含旋转版本），结果与失败状态写入`annotation_ocr_v3.json`缓存。缓存包含原图标识和算法版本，后续读取不重复识别；不调用Qwen或其他云端服务。局部图像保存在`annotation_ocr_pages/`，只用于定位，不修改参数或原始识别文件。

SVG气泡沿用15px半径，按实际屏幕像素进行有界、确定性的两轮避让：先避免气泡重叠，再避开文字框、减少引线交叉并控制长度。缩放或容器尺寸变化后重新布局自动气泡，平移复用布局；人工位置固定。自动避让结果只用于当前视图，不自动写回位置。空间不足时保留气泡并提示放大或人工调整。

自动证据定位页数沿用`QWEN_MAX_PAGES`（默认3页）；其余预览页仍可切换查看和人工标注。历史订单首次打开时依据原图与已保存候选补建，不重跑Qwen/RAG。PDF预览使用Poppler的MediaBox，PDF文本坐标转换包含裁剪偏移及页面旋转；OCR坐标按其来源图像尺寸归一化。

范围仅为压缩弹簧原图证据导航。当前不标注SolidWorks返回图，也不提供带标注PDF导出；对比查看器与SW程序不因此增加标注处理。

## 接口与持久化

`GET/PATCH /api/reviews/{job_id}/annotations`沿用订单权限。GET返回`source_document_id`、独立的`annotation_revision`、预览页清单、按字段关联的标注及定位警告；响应中的历史number不作为前端显示编号。PATCH仅接受`source_document_id`、`expected_annotation_revision`、`changes`；每项修改包含`annotation_id`、`location_id`、`page`、`anchor`、`bubble`，坐标均为0至1的有限数值。参数值等额外字段被拒绝。成功返回完整标注文档并增加标注版本；原图或标注版本不匹配返回409及服务器当前文档。

数据库模式只更新现有审图JSON中的`drawing_annotations`，使用行锁合并；正常参数保存同样保留服务器最新标注。无数据库模式独立保存`annotations.json`，使用跨进程锁与原子替换。标注写入不增加审图修订，不改变参数/确认状态、建议有效性、冻结参数包或SW任务。

响应新增可选`algorithm_version`（当前`original_annotation_locator/v3`）及`text_obstacles`（页码、归一化文字框）。后端原有15项标注记录和GET/PATCH请求格式保留，前端显示上述13项编号。旧订单首次GET时重建自动位置、增加独立标注版本；保留人工位置及ID，未知来源位置保留并提示核对。重建在数据库行锁外进行，最终在锁内合并最新人工修改；文件模式使用现有文件锁。升级失败保留旧结果和提示，并记录本版本已尝试，不反复自动重试。算法更新不改变`source_document_id`，原图本身变化时不套用旧人工位置。

## v3 数字证据与补定位

PDF 同一文字行内的拆分数字使用与 OCR 匹配、去重相同的解析规则；PDF 字形须沿同一方向相邻，不跨单元、公差列或文字行拼接。重叠结果保存来源别名及片段坐标。竖排尺寸正文与上下偏差分别处理，不把右侧数字或落入数值范围作为外径依据；无方向的碎片及无角色依据的 φ 标注不直接生成外径参数。

缺失外径、自由长度及粗糙度可以独立触发本地放大和 0/90/270 度识别。候选区域按文字、竖排框及连接的图形内容生成，不依赖外径和自由长度同时已定位。每页最多12个裁剪输入，结果按原图、算法版本、区域及旋转角缓存。只有实际执行的区域才记录完成；空区域保持未执行，失败和完成未匹配分别记录。正常读取不重复运行。

新增 `POST /api/reviews/{job_id}/annotations/relocalize`，仅提交 `source_document_id` 和 `expected_annotation_revision`。操作沿用订单权限及独立标注版本，只重试缺项/失败任务，保留已有可靠位置。版本变化（包括 OCR 执行期间发生的人工修改）返回409和最新标注；失败保留原位置并允许用户重试。补定位过程中浏览器暂停位置编辑，先完成待保存位置；切换订单后旧响应不重绘新订单。

响应可选 `diagnostics` 包含字段、原图与当前数值及单位、原文、页码、证据坐标、原因和定位状态。读取已有标注时优先采用该标注的单位，其次采用适用的同页单位依据，统一换算后按完整精度比较。比如 `0.072 in` 与 `1.8288 mm` 无需核对。无法确定原图单位时提示「原图单位待核对」。该比较直接复用保存的证据，不重新识别、补定位或改写参数、确认记录及坐标。

原图底部的「原图数值核对 · N 项」可用鼠标或键盘展开。零项隐藏入口，每次打开工作台默认折叠。工作台内换页、缩放及切换显示单位时保留展开状态。展开后可查看差异两侧的数值与单位，以及直径关系冲突等核对原因。

本地真实验收命令：`python scripts/test_drawing_annotations_v3.py --real` 和 `node scripts/test_drawing_annotations_browser.mjs --v3`。五份图纸、识别结果、缓存和截图保存在 Git 忽略的 `outputs/annotation-v3-qa/`；不调用云端模型或真实 SW。
