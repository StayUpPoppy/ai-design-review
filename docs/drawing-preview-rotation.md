# 审图原图旋转与摘要精简

摘要保留类型、图纸名称和图号，移除“状态”“ERP”“缺失字段”三张卡片。内部审图状态、缺失字段和生图就绪校验继续保留，已有确认及冻结参数不变。

审图原图工具栏在100%按钮右侧提供“左转90°”“右转90°”。每次围绕视口中心旋转90°，保持缩放倍率；连续四次恢复原方向。“适应窗口”采用旋转后的宽高，100%保留当前方向并恢复原尺寸比例。图片未加载或加载失败时不能旋转。

角度只存在当前预览会话的前端内存中。PDF每页单独保留本次角度，切页按该页方向适应窗口；关闭预览、切换订单或刷新后归零。普通订单和多规格子记录使用同一实现；多规格来源核对页与生图产物对比保持原有流程。

图片和标注共用正反坐标映射：锚点、引线和气泡位置随图转，编号保持正向，圆半径和文字大小沿用现状。旋转不重排气泡、不保存参数或标注，不修改上传文件。真正拖动或人工定位时，屏幕位置换算回原图归一化坐标后沿用原保存机制；方向键仍按屏幕方向移动。参数编号定位也使用同一映射。
