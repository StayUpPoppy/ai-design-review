# 多文件与文件夹上传

通过“选择文件”多选图纸，或使用“选择文件夹”读取其子文件夹；也可以把文件、文件夹一起拖入页面。文件夹拖入优先使用浏览器目录入口，并逐批读到目录结束。浏览器不支持读取拖入目录时，请改用文件夹选择或多选文件。

选择后先核对上传清单，不会立即上传。清单保留相对路径、文件名、大小及状态；每次选择或拖入都生成独立清单项，不按文件路径、名称、大小或修改时间去重。同一文件、同一文件夹可重复添加，排队、识别中和完成后都无需刷新页面即可再次上传，每次上传独立创建订单。支持 PDF、PNG、JPG/JPEG、TIF/TIFF、BMP、WEBP；空文件、不支持的格式、空目录和读取失败均单独提示。压缩包不解包。

每批最多50份待提交的有效文件，重复文件也分别计数。超过限制时须先移除部分文件，不会悄悄只取前50份。点击“开始识别”后，前端逐份向现有 `POST /api/reviews` 上传，收到入队结果即继续下一份，不等待识别完成。每份文件是一个订单，多页PDF仍是一个订单。服务器的 `RECOGNITION_WORKER_CONCURRENCY` 不变（默认2），上传数不等于识别并发数。

本批识别选项在开始时冻结；暂停和重试上传继续使用该文件原选项，新添加的文件使用下一批选项。“停止后续上传”等待当前请求结束，不取消已入队任务。暂停期间可以移除待上传文件，再点“继续上传”。上传期间也可继续查看或编辑其他订单，订单切换仍受现有保存保护。

上传区固定标题为“图纸上传”，分为待上传、识别进度、待处理三个区域。新增有效文件时仅自动展开待上传区域；识别进度和待处理区域默认收起，显示数量摘要。用户手动展开或收起后，进度刷新不重置操作；一个区域处理完毕隐藏后，再出现新任务时恢复默认状态。没有待上传文件时隐藏开始按钮，没有未上传文件时隐藏刷新丢失提醒。

清单与历史栏共享识别进度和轮询，不模拟百分比。上一批排队或识别中的任务继续保留，完成后自动移出明细；识别失败也移出明细，在历史栏查看原因并重试。上传失败、结果待核对、空文件、不支持格式及读取异常保留在待处理区。网络断开、网关超时或无效回执可能意味着服务器已接收文件，此时暂停后续上传并显示“结果待核对”：先刷新、核对历史订单，已有订单时移除此待核对项；确认没有创建后才重试，避免重复上传。失去登录或上传权限时暂停后续文件。

本批全部结束后只保留一行完成、失败数量提示及“清除提示”，不再显示“查看历史”；新增下一批有效文件后旧提示不再显示。结果未知时仍提供“核对历史订单”。前端批次标识仅用于统计，暂停续传、上传重试及历史栏识别重试不重复计数。多批并行时各自统计，旧批次完成不改变新批次结果。完成明细、跟踪对象和旧批次统计会释放，保留本页任务关联；清理展示不删除订单、不重新上传文件，也不会中断其他正在识别的任务。同名文件的移除、进度及订单删除均按独立ID处理，互不影响。

允许重复添加只适用于使用者主动选择文件。原清单项的重试、暂停续传和结果未知保护仍然有效，不会自动重复发起上传；再次选择同一文件会新增一项，原有失败或待核对项继续保留。

历史订单标题右侧的6px红点表示新一轮识别完成、尚未查看，与绿色“识别完成”标签并存。顶部“新完成 N”只统计当前列表可定位的未查看结果，点击仅滚动并聚焦第一项，不打开、不排序。首次成功读取列表时，已有完成记录建立已查看基线；本次提交或已观察到进行中的任务不被基线吞掉。重新识别按新轮次提示，参数编辑、确认和生图不产生红点。

成功加载并展示对应轮次的审图结果后才消除红点，单文件自动打开成功也算查看。加载、保存失败及刷新列表均不清除；旧响应不能清除更新轮次的提示。状态按服务地址和登录用户保存在当前浏览器，支持刷新重开、页面关闭期间已跟踪任务的完成提示及多标签页已查看同步。识别轮次缺失的旧完成记录按基线兼容；不使用审图修订号或参数更新时间判断新结果。浏览器存储不可用时退回当前页面会话状态，不影响上传和审图。完成提示清除与历史红点相互独立。

批量完成后不会自动切换当前订单，可从历史订单打开。单文件识别完成后，仅在当前订单、参数编辑状态和导航意图均未改变时自动打开；晚到响应不能抢占正在编辑的订单。

批次清单和未上传的本地文件只保留在当前页面，不缓存文件内容，也不发送本机绝对路径。关闭或刷新前若仍有未上传文件，浏览器会提示离开；刷新后需重新选择未上传部分。已入队任务继续后台运行，可从历史订单查看。历史列表使用现有接口允许的100条上限；本页批次任务不因列表截断而停止跟踪。

历史订单栏顶部“新建审图”右侧的侧栏图标可收起或展开历史栏。桌面向左滑动收起至40px窄栏，手机向上收起至40px高工具条；主内容区域同步调整，展开时恢复滚动位置及批量管理选择。滑动使用220ms、`cubic-bezier(0.16, 1, 0.3, 1)`缓动，内容保持正常排版宽度并被裁切，不压扁文字，按钮始终可用。连续点击从当前位置反向切换；缩放窗口或旋转屏幕时立即落到最后选择的状态。动画中的列表暂时不可操作，收起结束后才隐藏；后台识别进度及新结果红点照常更新，参数草稿、勾选项及上传队列保留。

首次默认展开，浏览器记住选择；首次加载、刷新恢复及系统开启“减少动态效果”时直接切换，不播放滑动。动画期间开启减少动态效果也立即完成切换。存储不可用时选择仅当前页面有效。按钮支持键盘操作并保留焦点，提示文字为“收起历史订单”或“展开历史订单”。

本功能只调整前端，无新增接口或数据库字段。更新前端文件和缓存版本后强制刷新即可；使用仓库当前前端挂载方式时不需要重启Docker。
