## 3. 参数补算公式

### 3.1 线径和各直径

| 编号 | 目标参数 | 当前公式 | 输入/优先级 |
|---|---|---|---|
| A01 | 线径 | d = (Do − Di) / 2 | 已知外径和内径 |
| A02 | 外径 | Do = Di + 2d | 优先使用内径、线径 |
| A03 | 外径 | Do = Dm + d | 无可用上一组合时使用中径、线径 |
| A04 | 内径 | Di = Do − 2d | 优先使用外径、线径 |
| A05 | 内径 | Di = Dm − d | 无可用上一组合时使用中径、线径 |
| A06 | 中径 | Dm = (Do + Di) / 2 | 直径补算器优先使用外径和内径 |
| A07 | 中径 | Dm = Do − d | 然后使用外径和线径 |
| A08 | 中径 | Dm = Di + d | 最后使用内径和线径 |

补算器依次处理线径、外径、内径、中径，后面的计算可以使用前面刚补出的数值。主要用于缺值或已标识为推导的参数，明确图纸值、人工值和已确认值不会因此被直接覆盖。没有实现“任意方程自动求解”，例如不能据此认为所有代数反推路径都已接入。

来源：[直径补算器](D:/YingKe/ai-design-review/src/ai_design_review/standardizers/diameters.py:49)。

### 3.2 有效圈数和单端支承圈数

| 编号 | 条件/参数 | 公式 | 说明 |
|---|---|---|---|
| A09 | 两端并紧的有效圈数 | n = n1 − 2ns | ns 是单端，不是两端合计 |
| A10 | 两端不并紧且磨平 | n = n1 − 1 | 不依赖 ns |
| A11 | 两端不并紧且不磨平 | n = n1 | 不依赖 ns |
| A12 | 对称并紧端的单端支承圈数 | ns = (n1 − n) / 2 | 要求 n1 > n，且两个圈数有独立有效来源 |

当前并紧端规则在 ns 真正缺失、未被人工主动清空且来源仍有效时，可按公司规则临时取 `ns = 1` 推导有效圈数；这是默认规则，不是图纸识别事实。人工清空、无效输入和过期值不能直接当作默认值使用。

禁止循环反推：如果 n 本身由默认 ns 和 n1 推导，不能再把这个 n 当作独立依据反推 ns。图纸明确两端不对称时，也不使用均分公式。自动支承圈数在圈数被编辑后等待两项当前圈数确认，再重算并重新待确认。

来源：[前端有效圈数](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:78)、[前端支承圈数](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:186)、[后端圈数规则](D:/YingKe/ai-design-review/src/ai_design_review/standardizers/coil_counts.py:15)。

## 4. 节距、名义压并高度和上限参考

### 4.1 并紧端模型的系数 a

| 端面条件 | 两端合计支承圈数 Ns = 2ns | 参数行单端 ns | a |
|---|---:|---:|---:|
| 两端磨削 | 1.5 | 0.75 | 1 |
| 两端磨削 | 2 | 1 | 1.5 |
| 两端磨削 | 2.5 | 1.25 | 2 |
| 两端不磨削 | 2 | 1 | 3 |
| 两端不磨削 | 2.5 | 1.25 | 3.5 |

当前是固定分档匹配，不在档位之间插值。明确端部条件未知、支承圈数不在上述档位、或 `n1 − n − 2ns` 的绝对值大于 `0.0001` 时，暂停该模型的几何补算。

### 4.2 节距和名义压并高度

| 编号 | 端部条件 | 节距 t | 名义压并高度 Hb_nominal |
|---|---|---|---|
| A13/A14 | 两端并紧，a 可确定 | t = (H0 − ad) / n | Hb_nominal = d(n + a) |
| A15/A16 | 两端不并紧、不磨平 | t = (H0 − d) / n1 | Hb_nominal = (n1 + 1)d |
| A17/A18 | 两端不并紧、磨平 | t = H0 / n1 | Hb_nominal = n1d |

节距补算结果必须满足 `t > d`。两端不并紧时还检查有效圈数和总圈数是否符合 A10/A11，不符合则暂停自动几何补算。

参数区缺少实际压并高度时，可以补入名义估算；它不是实测值，也不是含公差上限。图纸/人工高度优先保留，人工主动清空不回填。名义高度不依赖节距、自由高度或线径公差，但需要当前端部/圈数关系有效。

### 4.3 含公差的压并高度上限参考

| 编号 | 计算内容 | 公式 |
|---|---|---|
| A19 | 最大线径 | dmax = d + δd+ |
| A20 | 两端磨削上限参考 | Hb_limit = n1 × dmax；页面显示 Hb ≤ Hb_limit |
| A21 | 两端不磨削上限参考 | Hb_limit = (n1 + 1.5) × dmax；页面显示 Hb ≤ Hb_limit |

没有线径上偏差时按 0 处理，并注明“按名义线径”。上偏差草稿无效时不计算。磨削上限的现有依据文案注明“端面磨削约 3/4 圈适用”；代码按磨削状态选分支，没有另外从图纸验证磨削角度。

这里的 `(n1 + 1.5)dmax` 是上限参考，不能拿它替代不并紧、不磨平模型的名义高度 `(n1 + 1)d`。

来源：[前端模型分支](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:278)、[节距](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:299)、[名义高度](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:344)、[上限参考](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:110)。

## 5. 设计校核值、应力和重量

| 编号 | 结果 | 公式 | 单位/依赖 |
|---|---|---|---|
| B01 | 旋绕比 C | C = Dm / d | 无量纲 |
| B02 | 细长比 b | b = H0 / Dm | 无量纲 |
| B03 | 曲度系数 K | K = (4C − 1) / (4C − 4) + 0.615 / C | 要求 C > 1 |
| B04 | 理论刚度 k / P′ | k = Gd⁴ / (8Dm³n) | N/mm；使用有效圈数 n |
| B05 | 螺旋角，内部弧度 | α_rad = atan(t / (πDm)) | 代码使用 atan2(t, πDm)，有效正数时等价 |
| B06 | 螺旋角，页面角度 | α_deg = α_rad × 180 / π | ° |
| B07 | 展开长度近似值 | L ≈ πDm × n1 / cos(α_rad) | mm；使用总圈数 n1 |
| B08 | 单件重量/质量估算 | Q_kg ≈ (πd² / 4) × L × ρ × 10⁻⁶ | kg；d、L 为 mm，ρ 为 g/cm³ |
| B09 | 同一质量换算为克，便于人工对照 | Q_g = Q_kg × 1000 | g；当前页面 Q 仍显示 kg，不是新增界面计算字段 |
| B10 | 载荷点压缩量 | fi = H0 − Hi | mm；后端派生记录 |
| B11 | 缺少力值时的估算工作载荷 | Pi_est = k(H0 − Hi) | N；仅用于应力校核，不写回原载荷点力值 |
| B12 | 每个工作点的剪应力 | τi = 8PiDmK / (πd³) | MPa；每个非压并载荷点分别计算 |
| B13 | 缺少明确压并力时的估算压并载荷 | Pb_est = k(H0 − Hb_used) | N |
| B14 | 压并剪应力 | τb = 8PbDmK / (πd³) | MPa |

### 5.1 应力载荷和高度取值顺序

工作点优先使用该点已有的有效力值；没有力值才按高度和理论刚度估算。力值为 0 是有效输入；负数、非数字和不支持的单位属于无效输入，不会被当作“缺值”偷偷改用估算。

压并点按标签识别：`Fb`、`Pb`、`压并载荷`、`压并负荷`、`压并力`。存在唯一明确压并点且有有效力值时直接使用，不要求再用高度估算；多个压并点会提示歧义，不自动择一。

没有明确压并力时，Hb_used 优先采用有效图纸/人工高度；否则采用当前端型的名义高度。含公差上限参考不是实际高度，不直接拿来代入 Pb。有效估算要求 `0 < Hb_used < H0`；工作点估算还检查 Hi 不大于 H0，并在 Hb 可用时不低于 Hb。人工主动清空、过期或无效的实际高度不会自动回退为名义值。

应力计算使用 B04 重新算出的理论刚度，不是无条件使用参数行里图纸标注或人工输入的 `spring_rate`。有明确力值时，工作应力不依赖刚度和载荷点高度。

### 5.2 估算性质和适用范围

这些设计结果面向普通圆丝、圆柱、等节距螺旋压缩弹簧。明确为变节距、非圆丝或非圆柱时，设计引擎将除 C、b 外的相关结果标为不适用。特征未知不等于已经完成适用性验证。

展开长度按统一中径、节距和总圈数近似；质量公式未另外扣除端面磨削去除量，也没有增加镀层质量或工艺修正。不能把估算质量当作称重值。

当前不会自动将“工作应力”合并成某个新的“最大设计应力”参数，也没有按材料许用应力输出安全系数或合格/不合格判断。

## 7. 确定性标准化公差公式和完整分档

以下是当前配置为 `GB/T 1239.2-2009` 的项目规则表，仅描述本程序实现。单项精度等级优先于通用精度等级。标准化生成的是建议，不等于已经采纳或覆盖原参数。

### 7.1 受控外径/内径公差

公式：`ΔDs = ±max(aD × Ds, bD)`，Ds 为当前受控的 Do 或 Di。没有指定受控直径时，优先外径，有数值才使用；否则用内径。

表中每格为 `aD / bD(mm)`。

| 旋绕比 C | 1 级 | 2 级 | 3 级 |
|---|---|---|---|
| 3 ≤ C ≤ 8 | 0.01 / 0.15 | 0.015 / 0.20 | 0.025 / 0.40 |
| 8 < C ≤ 15 | 0.015 / 0.20 | 0.02 / 0.30 | 0.03 / 0.50 |
| 15 < C ≤ 22 | 0.02 / 0.30 | 0.03 / 0.50 | 0.04 / 0.70 |

例：Ds = 27 mm、C = 14、2 级，则取 `max(0.02 × 27, 0.30) = 0.54 mm`，建议为 `±0.54 mm`，不是将两项相加。

### 7.2 自由长度公差

公式：`ΔH0 = ±max(aH × H0, bH)`。表中每格为 `aH / bH(mm)`。

| 旋绕比 C | 1 级 | 2 级 | 3 级 |
|---|---|---|---|
| 3 ≤ C ≤ 8 | 0.01 / 0.20 | 0.02 / 0.50 | 0.03 / 0.70 |
| 8 < C ≤ 15 | 0.015 / 0.50 | 0.03 / 0.70 | 0.04 / 0.80 |
| 15 < C ≤ 22 | 0.02 / 0.60 | 0.04 / 0.80 | 0.06 / 1.00 |

例：H0 = 19 mm、C = 14、2 级，取 `max(0.03 × 19, 0.70) = 0.70 mm`。

上述两类公差在 C 不属于 3～22 时不外推。C 恰为 8 使用第一档，恰为 15 使用第二档，恰为 22 使用第三档。

### 7.3 总圈数公差

| 当前总圈数 n1 | 建议极限偏差 |
|---|---|
| 0 < n1 ≤ 10 | ±0.25 圈 |
| 10 < n1 ≤ 20 | ±0.50 圈 |
| 20 < n1 ≤ 50 | ±1.00 圈 |
| n1 > 50 | 超出当前规则表，不自动给值 |

这是按总圈数直接查档，不依赖精度等级。

### 7.4 垂直度、直线度和永久变形

| 编号 | 结果 | 当前公式/规则 |
|---|---|---|
| C01 | 1 级垂直度限值 e | e = 0.02H0 |
| C02 | 2 级垂直度限值 e | e = 0.05H0 |
| C03 | 3 级垂直度限值 e | e = 0.08H0 |
| C04 | 直线度限值 s | b ≥ 5 时，s = e / 2 |
| C05 | 永久变形限值 | δ_perm = 0.003H0，即自由高度的 0.3% |

单位均为 mm；程序把限值保存为正值及 `上偏差=限值、下偏差=0`，不是对称 ± 公差。b ≥ 5 时垂直度提示协商/人工核对，增加直线度建议。

规则表中约 `1.15° / 2.9° / 4.6°` 是各等级的已有说明常量，不是根据节距计算的螺旋角 α。

### 7.5 载荷和刚度公差

载荷公差：`ΔPi = ±r × Pi`。刚度公差：`Δk = ±r × spring_rate`，这里的基数是当前参数行刚度，不强制替换成校核区理论刚度。

| 有效圈数 n | 1 级 r | 2 级 r | 3 级 r |
|---|---:|---:|---:|
| 3 ≤ n ≤ 10 | 0.05（5%） | 0.10（10%） | 0.15（15%） |
| n > 10 | 0.04（4%） | 0.08（8%） | 0.12（12%） |
| n < 3 | 不自动计算 | 不自动计算 | 不自动计算 |

例：Pi = 16 N、n = 8、2 级，载荷公差为 `±1.6 N`。k = 1.8331 N/mm、n = 8、2 级，刚度公差为 `±0.1833 N/mm`（四位小数）。

载荷/刚度优先用各自专项精度等级，未指定时使用通用精度等级；有效圈数有当前值时优先当前值，缺失且可以推导时用端部规则结果。

## 8. 公差输入、百分比和单位处理

### 8.1 输入解析和百分比

| 操作 | 当前处理 |
|---|---|
| 普通公差输入 ±x | 保存上偏差 +x、下偏差 −x |
| 普通公差输入 +u/−l | 分别保存输入的上、下偏差，不自动对称化 |
| 标准化绝对载荷公差转百分比 | r_percent = abs(参考绝对偏差) / abs(P) × 100；保留 3 位小数 |
| 标准化参考偏差选择 | 优先上偏差；上偏差缺失才用下偏差绝对值，不是取上下偏差最大值 |
| 手工绝对载荷公差转百分比 | 力值非零且有上偏差时，abs(上偏差) / abs(P) × 100；保留 3 位小数 |
| 手工输入 ±p% | 保存 abs(p) 为百分比，并清空当前绝对上、下偏差；此函数不直接生成 ±Pp/100 的绝对公差 |

P 为 0 时不能做百分比除法。对不对称公差，界面记录的单一百分比不能完整替代上下偏差，应以实际上下偏差核对。

来源：[标准化载荷公差处理](D:/YingKe/ai-design-review/frontend/app.js:4614)、[手工公差解析](D:/YingKe/ai-design-review/frontend/app.js:12129)、[手工载荷公差](D:/YingKe/ai-design-review/frontend/app.js:12166)。

### 8.2 设计校核和载荷导出的单位归一化

| 输入单位 | 归一化公式 |
|---|---|
| mm / 毫米 | 长度_mm = 原值 |
| cm | 长度_mm = 原值 × 10 |
| m | 长度_mm = 原值 × 1000 |
| in / inch / 英寸 | 长度_mm = 原值 × 25.4 |
| N / 牛 | 力_N = 原值 |
| kN | 力_N = 原值 × 1000 |
| kgf | 力_N = 原值 × 9.80665 |
| turns / turn / 圈 | 圈数保持原值 |

绝对力公差随力值采用同一换算因子；百分比不乘长度或力的换算因子。未知单位不直接当作 mm/N；兼容旧数据时，缺少单位的字段按该入口既有默认单位处理。

重要边界：这不代表项目已具备“整张英制图纸自动转公制”的完整流程。直径补算、参数行刚度和部分标准化/派生分支直接使用参数原数值，默认其已符合 mm 等约定。排查时必须确认具体入口，不要仅凭设计校核支持 in 就认为识别、确认、标准化和 SW 建模全链路均完成了转换。

来源：[设计计算单位表](D:/YingKe/ai-design-review/frontend/compression-design-checks.js:6)、[载荷点导出](D:/YingKe/ai-design-review/frontend/solidworks-export.js:214)。

## 9. 前端导出相关的派生和舍入

前端本地参数包重新生成中径、C、b 的派生记录：优先已确认中径，否则用已确认外径和线径的差，再否则用已确认内径和线径的和。公式与 A07/A08、B01/B02 相同，不是新增物理公式。

| 位置 | 当前精度 |
|---|---|
| 一般页面紧凑数值 | 最多 4 位小数，去掉末尾 0 |
| 自动节距、圈数、名义高度等写入参数值 | 通常 4 位小数 |
| 参数行理论刚度、标准化公差、派生参数 | 4 位小数 |
| 设计校核内部链式运算 | 理论刚度、角度等保留计算精度继续使用，不强制使用页面已舍入数值 |
| 页面单件重量 Q | kg，最多 8 位小数 |
| 载荷高度、力值、绝对公差导出 | 归一化后 3 位小数 |
| SW 预览计算属性 P′、C、τ_b | 4 位小数 |
| SW 标题栏重量 | kg，8 位小数 |

SW 预览直接复用设计计算器，不另建一套应力/重量公式。实际输出还涉及当前任务的校验和冻结参数；旧任务不能用当前页面的新值来反推。计算值出现在页面，不等于已经人工确认或保存。

## 10. 会影响“不可用/需核对”的计算判断

以下是校核判据，不是新的可编辑参数；列出是为了排查页面提示。

| 判断项 | 当前主要表达式 |
|---|---|
| 基础有效性 | 线径、各直径、自由高度和圈数为正数；计算值必须有限 |
| 截面可成立 | Do − 2d > 0，否则阻断 |
| 内径一致性 | abs(Di − (Do − 2d)) > max(0.02 mm, 0.02d) 时警告 |
| 圈数关系 | n > n1 时阻断；对称并紧端检查 ns 与 (n1 − n)/2 |
| 当前直径/自由高度规则范围 | 3 ≤ C ≤ 22 |
| 当前总圈数公差规则范围 | n1 ≤ 50 |
| 细长比提醒 | b ≥ 5 时提示直线度/垂直度复核 |
| 自由高度与压并高度 | H0 必须大于可用压并高度，否则阻断 |
| 工作点高度 | Hi > 0、Hi ≤ H0，且不低于可用压并高度 |
| 力值 | Pi ≥ 0 |
| 同高度不同载荷 | abs(Hi − Hj) ≤ 10⁻⁶ 且 abs(Pi − Pj) > 10⁻⁶ 时警告 |
| 载荷趋势 | (Hi − Hj)(Pi − Pj) > 0 时警告，即高度越小但力值反而越小 |

载荷点对比会跳过明确属于不同 `test_height_type` 的点。C 超出规则范围、b 较大等不是自动认定不可制造，和几何不成立的阻断不同。

后端合理性检查缺少明确高度时，旧参考路径使用 `d + max(0, 线径上偏差)` 计算压并参考；而设计上限函数使用带符号的 `d + 线径上偏差`。常规上偏差非负时相同，上偏差为负时可能不同。这是当前实现差异，本次未修改；定位此类差异时应分别查看合理性检查和设计计算依据。

来源：[后端合理性检查](D:/YingKe/ai-design-review/src/ai_design_review/spring_feasibility.py:175)、[载荷关系](D:/YingKe/ai-design-review/src/ai_design_review/spring_feasibility.py:386)、[旧压并参考路径](D:/YingKe/ai-design-review/src/ai_design_review/spring_feasibility.py:425)。

## 12. 排查顺序和常见误用

1. 先核对公式真实输入及其来源：页面当前值、已确认旧值、图纸值、默认候选或冻结任务值可能不同。
2. 再核对单位：重量是 kg；G 是 MPa；应力是 MPa；ns 是单端圈数；刚度用有效圈数，长度/重量用总圈数。
3. 核对端型和 a 的分档，不默认所有压簧都用同一节距/压并公式。
4. 区分名义压并高度、实际输入高度、含公差上限参考以及最终应力采用的高度。
5. 区分参数行 `spring_rate`、设计理论刚度和实际载荷点；不能拿图纸刚度替代程序实际用于估算力的理论刚度。
6. 当前中径缺失时，不同入口有不同回退顺序：设计计算上下文/直径补算器可优先用 `(Do+Di)/2`；导出派生及旧刚度回退更偏向 `Do−d`。输入几何一致时相同，互相矛盾时需检查实际入口；不能只比较公式名称。
7. 设计校核对明确变节距模型不适用；旧参数行刚度计算器只检查弹簧族、形状和截面，未额外检查 `pitch_type`。出现一处有参数值、另一处不适用时，先看入口及特征，而不是直接判定舍入错误。
8. 已确认公式值依赖变化时通常保留旧值并标记过期；页面显示旧值不代表允许继续用于计算。检查 `derived_value_stale`、`formula_recommendation_stale`、依赖快照和新候选。
9. 材料、标准号、精度等级、旋向、端部形式、端面磨削、表面处理和图号等主要是识别、选择、映射或查表，不存在统一的“用尺寸计算出来”的公式。Ra 也是证据/人工确认值，不是从线径自动推算。
10. 页面可展开“设计校核值 → 计算依据 → 完整公式与输入参数”，逐项对照本次实际输入。固定公差规则另查建议依据和规则编号。
