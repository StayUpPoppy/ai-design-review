# 热卷精度反推与规格行证据

GB/T 23934-2015规则快照位于`config/spring_standards/gbt_23934_2015.json`，版本`hot-coiled-tolerances/v1`，来源为已检索核对的《热卷圆柱螺旋压缩弹簧公差标准摘录.md》，各项目保留条款/表号。参数编辑与标准化使用本地快照，不实时调用RAGFlow或Qwen。更新快照后运行`python scripts/sync_hot_coiled_rules.py`；`--check`检查前端副本一致。

热卷按T、1、2、3级匹配完整上下偏差区间，边界计入，报价整体取最严分项。内/外径限值按自由高度分段，以中径计算；自由高度按比例及最低限值；指定高度下载荷按载荷比例与“最低变形量×当前有效刚度”取大者。缺失高度、刚度或适用条件时不强行反推。总圈数固定公差、刚度一般/特殊公差不映射为分级。冷卷仍沿用GB/T 1239.2-2009的1/2/3级。

适用范围按摘录核实：线径8～60mm、中径≤460mm、自由高度≤9000mm、旋绕比3～12、高径比0.8～4、有效圈数≥3、节距≤0.5倍中径。不能判定时沿用默认2级待确认，并在原有简短提示区区分缺少公差、计算依据、超范围及未覆盖规则。原图明确等级优先；人工下拉或AI改选进入人工模式，应用系统建议不会重置独立公差快照，也不会反推覆盖人工等级。

多规格定位升级`multi-spec-locator/v2`，来源核验缓存`multi-spec-evidence/v2`。稳定规格ID通过同页唯一代号对应原图，再用真实横线或同代号列相邻记录定位建立行边界，模型原始区域保留。OCR分隔符噪声另需行号及至少两个工程值核对；重复代号、数字不同、跨页或证据不足不自动关联。多个并列表格缺少可靠分界时不借用整页同值数字。

已核实热卷表头`d×D1×H0`与本行复合尺寸共同建立D1内径身份。内径原公差随字段保留，外径/中径仅按公式补齐，不复制公差。自动气泡优先使用真实数字框，无法拆分时指向已核实的尺寸单元格，提示中标明参数和值；圈数按各自列头及当前行定位。公共材料使用单独核实的公共区域。

旧记录未人工改动或确认的错误自动直径在读取时形成修正草稿，原图响应、原值及来源继续保存；前端通过现有保存队列、修订校验和审计写回。人工值、确认值及来源不明值不静默改写。自动标注独立升级，仅刷新受影响的自动位置，保留人工位置。普通单规格不因此重建标注。原图、PDF/OCR缓存及预算复用，不增加云端调用。新增可选元数据不进入SW，历史冻结任务与重试保持原样。
