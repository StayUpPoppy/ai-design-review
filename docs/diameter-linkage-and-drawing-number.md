# 三径联动与可编辑图号

## 操作

圆柱、圆截面压缩弹簧首次人工编辑外径、内径或中径后，以最后修改项为主控、固定当前线径，立即重算另外两项：外径＝中径＋线径，内径＝中径－线径。后续修改线径仍保持主控直径。原图值、人工值和已确认值都会联动；数值或计算输入变化后，相关直径重新待确认。输入恢复为旧值也不会恢复旧确认。公差保留，仅将相关标准化结果标记过期。

缺少有效线径、直径非法、单位无法换算或内径非正数时，关联项保留最后有效值并标记失效，不能直接确认或生图。恢复有效输入后重算。旧订单打开不会自动启用新联动；非圆柱或非圆截面结构不套用该关系。已有公式推导的线径在启用后作为固定输入，避免外径与线径互相反推。

图号在原摘要位置直接编辑。未识别时可补填，也可清空；失焦或生成/切换前提交至现有保存队列。仅去首尾空白，保留 `00123`、`YD-001 23` 等字符串。失败保留输入并提供重试。图号不需要另行确认，不改变订单名称、文件名或ID。保存后历史订单提示同步更新。

## 数据和兼容

新上传或主动重新识别的圆柱压缩弹簧，优先按原图的内径、中径、外径文字或已核实规格列归类。只有直径符号或数字时，程序检查尺寸线两端和界线。钢丝剖面可用于区分三径，普通视图中相对的多圈外轮廓也可用于核实外径。局部 OCR 可恢复竖排数字和分别印出的上下偏差。缺失偏差留空，同一标注的公差证据冲突时保留待核对。

同一原图标注的重复候选合并。已核实的粗糙度只排除指向同一标注的直径候选。原图尺寸和类型证据明确时直接归入对应参数，证据不足时才显示“直径类型待核对”卡片。可以选择类型后保存，由公式补齐缺少的直径，再按参数表现有流程确认。公差留在原图标注所属字段，核实位置用于该字段的气泡。

每张直径核对卡片右上角的 × 表示“忽略此候选，改为手动填写”。无需二次确认、不提供撤销。保存中显示“正在关闭”，成功后移除卡片；失败保留卡片与重试入口。忽略状态随订单保存，刷新、重开仍有效，不改变已有参数、公差、确认、联动或原图位置。忽略只解除此候选的类型核对阻断，参数表的必填、合法性、确认和其他生图检查继续执行。

`diameter-candidates/v1`统一区分原图候选和模型推导值，包括“计算值：”“计算结果”“推算”“推导”、文字运算及公式。按每个候选的数值分别判断，同段说明中的真实原图标注仍保留。比如外径12、线径1.6对应的中径10.4由公式计算，不显示10.4的类型核对卡片；计算参数保留原有来源/公式显示和确认流程。历史订单尚未采用的明确计算候选也在展示与生图校验时过滤；已采用候选和人工数据不改写。过滤仅使用已保存文本与证据，不做OCR、模型调用、读取时写库或重新识别，原始候选保留追溯。

`diameter-role/v3`补充无剖面圆的简化画法：在同页、同视图和同规格内，核实两侧重复圆弧、钢丝中心引导线及尺寸线两端。钢丝中心、内缘和外缘分别对应中径、内径和外径；仅一根虚线或数值差不能单独证明角色。嵌套尺寸分别关联自身文字及最近的尺寸线。重复圆弧半径也用于排除圈线交叉形成的伪剖面圆，真实剖面与圆弧证据冲突时继续待核对。原图毫米值只取文字，不按像素比例换算。

原图标注与模型推导解释分开保存。模型说明同时提及线径或“推算”时，不再整条删除原图直径；模型纯推导记录保存在`dimension_evidence`及可选的`diameter_role_evidence.model_derived_candidates`，不进入三径融合。可靠的轴向端面尺寸退出直径候选，保留长度依据。实际核验只接受本地OCR执行结果或PDF原文，不把模型自带的文字框当独立证据。

外径漏项补核优先复用同页的 PDF 文字层和带坐标 OCR。表格按栏名、符号、数值、单位匹配同一行。图形标注结合尺寸线核对后置 `O.D.`，需要时每页追加一批局部 OCR，分别读取名义值、类型和上下偏差。环规说明保留在技术要求中。已可靠填入的尺寸和能定位的核对卡片直接沿用。

名义值及类型清楚、公差读数未核实时，保留直径和原图读数，公差留空并标记待核对。填写有效偏差或在公差编辑器中明确清除后，可以单项或批量确认。旧单通过后台复核漏项，沿用原有版本和修订保护。部署时重建 API、Worker，浏览器按 Ctrl+F5 刷新。无需数据库迁移。

缺失中径不再补协议默认23；尚未人工采用的默认直径及其派生值不参与三径建议、刚度、重量或精度计算。已确认或实际人工填写的值仍可使用。新规则只在新上传、主动重新识别时归类原图；普通打开不修改已有直径或人工位置。

离线样例基准：2426AM-95为线径2、中径28、内径26、外径30；1624CA-38为线径6、中径48、内径42、外径54，70只作自由长度；3624CA-38为线径7、原图中径47及内径40、派生外径54。原图中径使用6号气泡，内径使用5号，派生尺寸不补造原图锚点。

待核对记录使用可选的 `diameter_role_candidates`，选定后以 `diameter_role_selected` 记录审计。忽略使用现有审图PATCH的`diameter_role_ignored`事件，`metadata.candidate_id`指定候选；后端校验保存的候选后设置`ignored=true`，旧记录缺省为false。忽略专用回执`diameter_role_update`只含`candidates`和`candidates_only=true`，前端仅合并候选，不回填工程参数。纯忽略保存使用服务器快照，不触发计算、标准化和确认撤销；混合手填事件仍按原保存流程处理。重复忽略幂等，已采用候选拒绝忽略，修订冲突按最新候选状态重试。未归类的值不进入参数融合，仅未选定、未忽略且非推导的候选暂停生图。生图就绪缓存同时使用候选状态和来源规则版本。内部候选不进入SW请求，无需数据库表结构迁移。

- `drawing_summary.drawing_no` 仍为可选字符串；空值表示未填写。新参数包使用当前已保存图号生成 `source.drawing_no`，新SW请求将非空字符串写入 `titleBlockProperties.客户图号`。历史任务、冻结请求及原参数重试保持原图号。
- 审图JSON可选 `diameter_linkage`：`version: compression-diameters/v1`、`driver_field`（三种直径之一）、`inputs`（主控直径/线径的实际值及单位）、`status: calculated/invalid`、`reason` 和首次联动前的 `original_parameters`。仅供内部状态恢复，不进入SW。
- 关联项用 `diameter_linkage_managed` 和既有公式元数据记录依赖，避免旧补全逻辑覆盖新关系；错误原因使用 `diameter_linkage_error`。原图证据和修改前值保留在原记录、联动快照及审计中。
- `diameter_linkage_updated` 审计事件记录整组参数、联动元数据和相关确认状态。修订冲突时以线径和三径为一组选择服务器值或本地值，不能逐项混合；图号按独立字段合并。
- 精度反推保留独立公差快照。系统联动的名义值不升级为独立输入；反推所需的当前几何由主控直径和线径计算，人工选择精度仍保持人工模式。
- 复用现有PATCH、修订号、保存队列、权限及审计，无新增接口或数据库迁移。
