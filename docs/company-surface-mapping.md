# 公司表面处理名称与中文成图

新上传沿用整图 Qwen 请求，逐条取得技术要求及原图位置。程序在同页、同规格内使用 PDF 文字层和带坐标的 OCR 核实表面处理。读数有冲突、残缺或过于宽泛时先放大对应行做本地 OCR，仍有疑点时将可定位的行合并到一次 Qwen 局部补读。请求超时或原文仍有疑义时，相关卡片显示「表面处理原文待核对」，可展开查看原图局部和读数。整图识别缓存回放只使用已有资料。

## 识别与编辑

公司库提供标准名称和 ID。「抛丸」「涂清漆」「镀锌五彩」分别使用「抛丸」「油漆-清漆」「电镀-镀彩锌」，只替换工艺名称，保留同一条里的其他工序、部位、数值和单位。明确的工艺代号仍可转换成中文。仅有「涂漆」「喷丸」「锌铝涂层 / ZINCFLAKE」等原文时，公司类型留空，中文正文核对后仍可确认。原图复核状态和证据保存在审图 JSON 的 `surface_mapping.verification`。

表面处理卡片显示一个公司名称下拉框。搜索框位于展开面板顶部，下方是可滚动的目录选项。可以用方向键和回车选择，Esc 关闭。目录加载失败时可在卡片内重试。复合工艺按原图顺序匹配，其他工序及条件保留正文。直接编辑正文时采用正文中第一个明确公司名称。

- 改选名称时，原名称或已维护的工艺术语能唯一定位即可替换对应片段。保留厚度、部位、等级、工序及否定条件。无法安全替换时保留全文，并提示核对正文中的工艺名称。
- 修改正文：本地识别完整公司名称并同步第一项，不调用Qwen。模糊写法不推测；选择“未指定公司类型”后保留正文，后续编辑不会恢复选择。
- 原文待核对且正文完整时，可点击「核对后确认」。无有效读数冲突的条目也可参与批量确认。存在有效读数冲突时，展开识别来源对照后单项确认。单项和批量沿用现有审计，记录确认的正文、目录选择和确认方式。
- 只有栏名、正文残缺、单位待核对或公司类型与正文不一致时先补正。明确选择「未指定公司类型」可以保留并确认完整正文。尚未选择公司类型时，确认可采用唯一明确的目录匹配，例如「镀锌五彩」对应「电镀-镀彩锌」。
- 公司目录读取失败时提供原位重试；正文和原始依据保留。

自动转换和人工修改均保持待确认，复用现有保存队列、修订号、审计及冲突决策。旧多ID记录打开时只显示第一项，不改原选择数组或确认；下次编辑／确认后规范成单项，新参数包冻结一个公司类型。重复来源仍独立保存和审计，界面按完整正文、条件及范围分组；不同厚度或部位不因公司名称相同而合并。

新版识别只处理上线后创建的上传任务。已有订单保留原结果和确认状态，可以用新版下拉框人工编辑。更新后重建 API、Worker，浏览器按 **Ctrl+F5** 刷新。无需数据库迁移。

新识别将表格栏名与工艺正文分开。已有订单打开时，编辑框、确认单及新生成的 SW 预览只显示一次开头的「表面处理」，原图摘录和历史冻结请求照原记录保留。

### 原代号来源关联

`surface_source_links`在同一审图内将已转换要求的原文与未人工改写的OCR正文比较：规范全半角、首部编号及表面处理标签，忽略句末分号等排版差异；保留内部标点、大小写、数值、否定词及全部附加条件。必须同页、范围相同，双方都有坐标时需兼容；只能关联到唯一中文转换组，位置冲突、人工改写或多个不同中文候选不自动关联。

例如“6. 表面处理：Fe/Ep.Zn15.P.c2C(除氢);”与OCR“Fe/Ep.Zn15.P.c2C(除氢)”在现有截图条件下关联成功。中文卡片的识别来源展示两份记录及各自ID、来源、页码和位置；OCR原文不再单独计入待确认或输出。中文未确认、正文清空或公司选择冲突不会让原代号复活。

原记录和确认状态保留，读取投影不修改审图或调用模型；下次正常保存时将服务端复核的`surface_mapping.source_requirement_ids`存入现有JSON并审计。该来源关联不参与公司选择确认快照，不因增加追溯信息撤销已有确认。客户端伪造来源ID不能隐藏其他条目。删除卡片同时处理关联来源，现有撤销可完整恢复。

## 保存与输出

审图技术要求可选元数据示例（实际ID见目录）：

```json
{
  "type": "surface",
  "content": "表面处理：电镀-镀彩锌，镀层厚度≥15 μm，彩虹铬酸盐处理2级C型，并进行除氢处理。",
  "standard_content": "表面处理：电镀-镀彩锌，镀层厚度≥15 μm，彩虹铬酸盐处理2级C型，并进行除氢处理。",
  "original_content": "Fe/Ep.Zn15.P.c2C（除氢）",
  "surface_mapping": {
    "catalog_version": "company-surface-treatments-v1-20261023",
    "catalog_ids": ["sfc_3e93f82d1852"],
    "selection_mode": "auto",
    "conversion_status": "converted",
    "input_snapshot": {"content": "Fe/Ep.Zn15.P.c2C（除氢）", "type": "surface"},
    "conflict": false
  },
  "need_human_review": true
}
```

`selection_mode`为`auto`／`manual`／`none`（主动未指定）。新`catalog_ids`最多一项；可选`source_requirement_ids`为原文来源ID数组。`content`是唯一出图正文，`standard_content`与它同步；下拉名称不额外拼接。确认快照包含正文、类型、范围及公司选择。服务端保存时复核关联，变更撤销旧确认，冲突或转换未完成不能通过伪造确认进入新任务。

确认并保存后，前端预览、手动／对话导出和后端请求的`technicalRequirements.技术要求`均为上述完整中文正文（最终统一编号）。原文及代码只保存在内部审图、证据和冻结包中；已转换来源的原代号不会从参数模板、结构化重复条目或旧文本回退再次追加。新任务冻结结果，历史冻结SW请求及原参数重试继续原样。

旧订单打开不自动转换、不调用Qwen、不静默改写正文或确认状态；可人工选择、改写并确认。无需数据库迁移。
