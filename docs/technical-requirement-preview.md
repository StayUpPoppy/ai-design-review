# 成图技术要求预览

在“参数”的“技术要求”区顶部查看“成图技术要求预览（N条）”。这里展示当前可输出的完整文字，包括参数自动项与已确认、有效的原图／人工要求，沿用SW的去重、排序和连续编号。生图页不重复展示。

正文不自动冠以寿命、热处理、工艺、硬度、盐雾、环保或其他分类标签；仅保留“表面处理：”一次。具体说明如“耐久试验：”“时效处理：”和自动参数项保持原样，与编辑框、确认单和SW输出一致。分类及原始正文继续保留在下拉框和来源中。

- 带“自动”的内容来自参数，点击可定位参数；调整相应参数即可修改自动项。其他可定位的条目点击返回原编辑卡片。
- 正文通过原参数或原图卡片修改；每条预览右侧提供“删除”，自动项也可删除。原图卡片保留原有编辑、确认、删除入口；单独删除重复原图卡片不会关闭对应自动项。
- 完全等价的原图卡片显示“已包含在自动项中，成图仅输出一次”。重复提示不隐藏待确认、翻译失败或保存失败等状态。
- 人工新增与自动项重复时显示行内提示，仍可提交为待确认记录；原图／人工记录之间原有的重复新增检查保持不变。
- 数值、公差、作用范围和完整条件都必须等价。部分重合、额外工艺、不同角度或否定条件分别保留；F／P载荷编号不作互换。
- “原图／人工要求”的记录数和待确认数量不包含自动项。没有可输出内容时，提示先确认参数或技术要求。

预览默认展开，长内容在区域内滚动；本次打开期间保留折叠状态，切换订单后重新展开。所有预览标记和来源信息只用于界面，不进入SW正文。

## 逐条删除及撤销

点击预览中的“删除”无需弹窗，条目、数量和连续编号立即更新；自动条目只取消本次技术要求文字，不删除参数或载荷点，也不改变其确认状态、标题栏和建模字段。完全等价的关联原图／人工记录同时从编辑卡片移除，原始识别文件和审计保留；部分重合或附加条件不同的要求不连带删除。

删除自动项后保存重开仍保持删除。相关实际值、公差、端部条件或部位改变时，旧选择失效，新条目满足原有确认条件后重新出现；仅确认、保存、刷新或无关修改不会恢复。载荷按稳定ID关联，重新排序不会串项。合并圈数整条删除；全部删除后SW技术要求为空字符串，不补默认项。新人工添加的同文记录独立处理，确认后仍可输出。

“撤销上一次删除”同时用于预览和原卡片，只保留本次页面最后一次删除，切换订单或刷新后入口消失；不增加已删除列表。撤销不回滚参数。若对应参数已经变化，自动项按当前值重建，关联旧原文恢复为待核对，避免将旧确认正文重新输出。

审图JSON的可选`technical_output_deletions`保存`source_key`、相关`fields`／`load_point_ids`及`basis`生成依据快照。删除仅匹配当前来源与完整依据，不按编号或正文全局屏蔽；确认状态和证据说明不参与依据比较。元数据走现有保存、修订冲突合并和审计；保存失败保留本地选择，通过预览上的“重试保存”继续。旧记录缺少元数据时沿用原规则。

## 草稿与服务端核对

输入期间按当前草稿副本刷新，不修改参数或确认状态，也不为刷新预览重建编辑卡片。未保存、保存中和保存失败会显示相应草稿提示；保存失败保留本地内容。

保存成功且订单就绪时，复用已有的`GET /api/reviews/{id}/generation-package`读取该修订的`solidworks_preview.extraProperties.技术要求`，以服务端文字为准。响应增加可选`technical_requirements_projection`（`text`和带稳定来源、关联ID、依据快照的`entries`），不进入SW请求或冻结参数包。兼容旧响应，能唯一对应本地条目时仍可操作，无法对应时不猜测来源。成功结果按服务地址、用户、订单及修订缓存，避免逐字请求。核对失败保留草稿，并提供“重试核对”；不会将读取失败显示成无技术要求。

请求同时检查订单打开轮次、本地编辑序号及数据快照，编辑或切换后旧响应失效。本地导入数据只显示本地草稿预览。图纸版式和姓名的输入校验不妨碍查看技术要求。

## 实现与验证

前后端SW输出生成器统一返回正文及来源投影；去重后再应用输出选择，最后连续编号。`TechnicalRequirementPreview`负责渲染、删除入口、重复提示及服务端核对；操作交由原保存队列处理。不新增业务接口、SW字段、数据库字段或迁移。

离线验证：

```powershell
node scripts/test_solidworks_export_ui.mjs
node scripts/test_technical_requirement_preview_browser.mjs
.venv/Scripts/python.exe scripts/test_technical_output_deletions.py
node scripts/test_technical_output_deletions_ui.mjs
.venv/Scripts/python.exe scripts/test_technical_output_deletions_api.py
```

共享样例比较前后端最终正文；浏览器测试使用模拟API，覆盖空原图列表、来源定位、重复新增、删除撤销、保存失败、修订缓存、服务端失败、晚到响应、用户和服务隔离，以及窄面板。不会调用云端识别或生产SW。

本次包含后端输出及响应类型调整，测试通过后执行`docker compose up -d --build api worker`并检查健康，再Ctrl+F5刷新。相关JS/CSS缓存版本为`20261102-technical-output-delete`。历史冻结任务及原参数重试不变。
