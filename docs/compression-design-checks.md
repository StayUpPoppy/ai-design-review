# 压缩弹簧设计校核与即时联动

适用于普通圆丝圆柱弹簧，普通订单和多规格子记录共用规则。计算结果逐项保留公式、实际依赖及来源；不修改材料目录、不代替材料许用应力判定。当前版本为 `compression-design-v3`。

## 输入、单位与圈数

`coil/coils/turn/turns/圈`按圈数读取，不修改原数值；`coils/end`等每端单位仅用于单端支承圈数。长度支持mm/cm/m/in，力值支持N/kN/kgf。单端支承圈数不再默认1；未确认的旧协议默认有效圈数8不能用作计算依据，也不再重新填回。

两端并紧且对称、总圈数和有效圈数具有独立原图或人工依据时，可补算 `S=(N-n)/2`；有明确单端支承圈数时，可补算 `n=N-2S`。一个关系生成的数据不能反向作为同一关系的独立输入。英文 `Number of End Coils: Each One of Two Ends`表示每端1圈；两端合计和推测文字另行分类，不信任模型自报来源。

原图明确值、人工填写及人工清空继续保护，关系冲突只提示核对。端部优先读明确文字，不能仅根据示意圈间距决定是否并紧。两端不对称时不按均分补算。

## 即时重算与确认

有效输入后，自动有效圈数、单端支承圈数、节距和名义压并高度立即按依赖顺序重算，不等待输入逐项确认。原自动值即使已确认，也更新为待确认；数值不变但实际依赖改变同样撤销旧确认。仅确认、保存或无关修改不会重复撤销。

输入未完成、非法或缺少依据时，保留最后有效自动值并标记失效，停止供下游计算使用；输入恢复后重算。原图和人工值不会被该机制覆盖。用户点击现有单项或批量确认入口确认当前可见结果，无新增确认步骤。

`automatic_calculation_adjustments`记录变更前后和规则版本；`support_coils_original`保留原识别信息，`support_coils_adjustment`兼容原审计。GET只返回修复视图，不写审图数据库或修订；通过现有保存队列、CAS与审计落库，失败和晚到响应保护保持现状。

## 节距与压并高度

节距优先采用原图值。缺值才使用现有端部公式 `t=(H0-a*d)/n`；单端支承圈数需乘2查现有表：磨平时合计1.5/2/2.5圈分别取a=1/1.5/2，不磨时合计2/2.5圈取a=3/3.5。未知或未覆盖端型不补造系数。原图节距与公式不同时保留原图值并显示简短核对提示。

两端不并紧使用既有补充模型：不磨平时 `n=N`、`t=(H0-d)/N`、`Hb=(N+1)*d`；磨平时 `n=N-1`、`t=H0/N`、`Hb=N*d`，不依赖支承圈数。

压并高度区分原图/人工实际值 `input_height`、名义估算 `nominal_estimate` 和上限约束 `reference_limit`。缺值且端型依据完整时补算名义值并待确认。`Hb≤某值`不是实际高度，不能直接用于应力；旧上限及原确认保留于 `legacy_reference_limit`。人工清空或失效的实际高度不回退为名义值。

本地节距恢复 `pitch-evidence/v1`复用PDF/OCR：明确节距文字，或与相邻重复钢丝截面及尺寸线可靠对应的数字，才可作为直接证据；普通数字、表格单元和水印不能仅凭数值被采用。按同页/同规格区域限定，多个不同值保留待核对。共享原有OCR缓存和每页局部预算，不调用云端模型。`pitch_recovery`保存恢复前值，后续仍需人工确认。

## 刚度、应力、重量

理论刚度独立展示：`k理论=G*d^4/(8*Dm^3*n)`。压并载荷有唯一明确力值时直接使用；没有时 `Pb=k采用*(H0-Hb)`，要求 `0<Hb<H0`。k采用优先为已确认、有效且单位支持的输入刚度，否则使用理论刚度。安装/工作载荷不当作压并载荷；未知名称不自动判为压并用途，可选 `load_role=working/solid/unknown`明确区分。

`C=Dm/d`、`K=(4C-1)/(4C-4)+0.615/C`、`τb=8*Pb*Dm*K/(π*d³)`。每个工作点独立计算，不修改原力值。应力结果保留实际Pb、Hb，以及 `inputs.spring_rate_used`（N/mm）和 `spring_rate_source`（input/theoretical）；`source_fields`只列实际依赖。

`L≈N*sqrt((π*Dm)^2+t^2)`，`Q≈π*d²*L*ρ/4*10^-6 kg`，ρ使用g/cm³，尺寸使用mm。已有直接节距时，重量不依赖支承圈数或有效圈数。材料缺少可用密度时明确说明原因，不填0；本次不扩充UNS N10276等材料，不新增端面磨削扣重模型。
