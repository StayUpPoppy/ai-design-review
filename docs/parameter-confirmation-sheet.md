# 弹簧参数确认单

压缩弹簧“结构化尺寸数据”标题栏提供“预览确认单”。普通订单与多规格子记录共用报告规则，只生成当前订单／规格的内容；来源记录需先打开对应子规格。

## 报告内容

确认单依次包括最终参数表、独立的载荷测试点小表、技术要求、待客户澄清事项及统一客户确认区。

- 参数只列材料、线径、外径、内径、中径、自由长度、总圈数、有效圈数、旋向，沿用原参数编号1—8、10。有效的图纸值、人工值及已有派生值均可列出，不打印计算过程，不要求先在内部逐项确认，也不打印逐项“已确认”标记。
- 表面粗糙度、端部形式、端面磨削、是否制扁不进入参数区、打印选择或各自的专属异常。其他高级参数及独立设计校核结果也不报告。内部参数编辑、确认、计算、生图校验及SW请求保持原规则。
- 原图技术要求保持现有中文显示及等价去重，正文完整保留。即使正文含粗糙度、并紧、磨平或制扁，也不会按关键词删句。
- 载荷点沿用原编号，保留测试高度、力值及公差；0 N不会当作缺失。缺项、非法值、重复编号及真实冲突需客户澄清。

## 正常与异常

真实缺少必填项、非法值、标注冲突及相关实际风险移入“待客户澄清事项”。必填规则来自当前模板；空白可选项直接省略，不生成补充问题。尚未采用的系统默认候选不能作为原图事实，依赖这些候选的派生值和诊断也不会冒充有效图纸信息。

单纯内部待确认、未采用建议、公式条件不足、过期派生值及后台检查失败不自动成为客户问题。过期派生值在预览上提示内部处理；诊断不可用时保留当前已知明确问题，并在预览提示内部复核，提示不进入纸张正文。

每个参数、载荷点或技术要求只出现一次：异常项目从正常区移除，保留原编号。同一项目的问题合并；跨字段的同一矛盾集中列出相关编号，当前值按“项目名＋数值＋单位”对应展示，并同时保留具体异常原因与客户确认要求。相同原因和提问去重，保留不同问题。历史诊断只有原因时补充针对相关项目的确认要求；只有提问时保留提问，不编造原因。

例如总圈数6.5圈、有效圈数8圈，合并列出参数7、8及两项当前值，说明“有效圈数不能大于总圈数”，并请客户确认两项正确数值。圈数矛盾不再追问已排除的端部形式。纸张不输出规则编号、后台状态、完整计算过程或内部依据，必要的异常条件仍保留。

异常区采用紧凑条目，每条下方统一为“客户回复：”加一条连续横线，由客户自行填写。单项参数、合并参数、载荷点及技术要求均使用同一格式，不预设填写项目、单位或选项。横线以边框绘制并适应版心宽度，始终保持一行；长条款自动换行、完整续页。没有异常时隐藏该区。

## 预览与打印

1. 点击“预览确认单”会结束当前输入并等待现有保存队列。保存失败保留草稿，点击“刷新预览”重试。失败时不能打印旧快照。本地导入数据无需写入服务器，纸张注明“本地数据”。
2. 打印选择只列本次可报告项目，默认全选。每个选项使用原参数／载荷／技术要求的稳定ID。在正常区与异常区间移动、刷新、暂时消失后恢复，均保留本次预览中已有选择。异常合并不强制重新勾选，取消项目不会重复打印。
3. 点击“返回修改”可回原编辑区。参数或材料依据发生变化后停用旧预览打印；刷新后获取新快照。
4. “打印／另存为PDF”打开浏览器打印窗口。选择A4纵向、100%缩放，可打印或另存PDF。关闭浏览器自带网址等页眉页脚。打开、勾选、打印及取消打印均不会确认参数、采用建议或修改审图数据；打印关闭也不代表打印成功。

窄屏下选择栏可折叠，纸张按屏幕宽度缩放；打印使用同一份内容，不进行整体缩放强塞一页。首期不附原图、不归档确认单，不提供电子签名、在线回传或可填PDF表单。客户反馈后由工作人员在原参数区修改、确认和保存。

## A4版式与Logo

标题“弹簧参数确认单”统一14pt，右上留白，不带样例标识。保留图纸名称、图号、规格、制单人和日期。正文默认9.5pt，优先收紧表格、行距和段间距，必要时切换9pt紧凑版，仍超长则完整续页。可用正文高度261 mm；实际分页以打印窗口为准。

固定使用 `frontend/assets/incospring-logo.png` 原始蓝色Logo，等比例宽38 mm。屏幕预览顶部显示一次，打印／PDF每页重复页眉，包括末页签字区。页眉高14 mm，与正文相隔4 mm；页边距上24 mm、左右及下12 mm。Logo作为前景内容，关闭背景打印仍保留，支持黑白打印。

固定静态Logo首次请求最多等待10秒，图片、打印图片及字体就绪后才启用打印。资源错误或损坏时禁用打印并提示刷新重试；失败保留打印选择。图片加载、文档渲染和诊断响应均按订单及请求轮次隔离，晚到响应不能启用其他订单或旧预览。

## 实现与数据保护

`frontend/app.js` 建立确认单专用投影，独立于内部审图和生图规则；`frontend/parameter-confirmation-sheet.js` 负责归类、选择、HTML及A4排版。构建只操作审图副本，使用现有只读 `POST /api/reviews/reasonableness` 获取确定性诊断，不调用识别模型或SW。

预览指纹覆盖编辑计数、修订、实际报告依据与材料目录。保存及诊断期间切换订单会关闭旧预览。文本统一HTML转义，预览iframe禁用脚本，仅允许同源访问与浏览器打印。品牌、选择和客户回复空白不写入审图JSON、审计或SW参数。
