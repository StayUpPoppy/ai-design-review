# A4参数确认单

压缩弹簧审图的“结构化尺寸数据”标题栏提供“预览确认单”。普通订单和多规格子记录分别生成当前规格的确认单；来源规格清单提示先打开对应规格。缺失、待确认或异常参数不阻止使用。

## 使用

1. 在原参数区补充或修改参数，点击“预览确认单”。入口结束当前输入并等待现有保存队列；保存失败时保留草稿，使用“刷新预览”重试，不显示旧数据。导入的本地数据无需保存到服务器，确认单注明“本地数据”。
2. “选择打印项目”按输入参数、载荷测试点、设计校核结果、技术要求、问题与建议的顺序分组，默认全部选中。左侧可取消项目；选择仅在当前预览有效。窄面板的选项可以折叠。
3. 建议来自现有公式、标准及项目参考值，始终标为“待确认建议”；缺失值显示“待补充”，不补成0。不同建议保留独立方案，无可靠依据时只提问题。过期建议不展示旧数值，能够本地重算的公式重新计算。
4. 需要改正式参数时点击“返回修改”。参数更新后旧预览暂停打印，刷新后使用新快照。
5. “打印／另存为PDF”打开浏览器打印窗口。纸张选择A4、纵向、缩放100%，可选择打印机或另存PDF。浏览器附加的网址、标题页眉页脚可在打印设置中关闭。内容自动分页，表头重复；无需把所有内容压到一页。

确认单包含名称、图号、规格代号、当前登录制单人和日期，不展示审图修订。每行提供两只初始空白的纸面方框“正确／需修改”，以及手写修改意见栏；末尾客户意见、确认人及日期留空。内部“已确认／待确认”不作为客户确认结果打印，也不因打印或纸面选择变更。长技术要求保留完整正文，问题表中的当前内容使用短摘要并指向正文。首期不附原图，不归档确认单，不提供电子签名、在线回传或可填PDF表单。

## IncoSpring页眉

确认单统一使用 `frontend/assets/incospring-logo.png` 原始Logo，蓝色、等比例、宽38 mm。页眉左侧Logo、居中的“弹簧参数确认单”标题与细灰色分隔线组成14 mm高的页眉，正文相隔4 mm。连续A4屏幕预览顶部显示一次；打印／PDF使用浏览器分页页眉，每页重复，包括表格续页及最后签字页。A4页边距为上32 mm、左右及下14 mm。

当前Chrome／Edge的分页页眉已验证。打印不使用负偏移固定元素，避免短末页漏印。原始PNG仅作等比包装后用于分页页眉，图片作为前景内容，关闭背景打印仍保留；不修改原图文件或加入图床依赖。

Logo从随前端发布的固定静态路径读取并内嵌打印文档，首次请求最多等待10秒，成功后同页复用。图片、打印图片及字体就绪后才启用打印；资源错误或损坏时保持禁用，提示点击“刷新预览”重试。保留已有打印选择，失败不改参数或确认状态。按订单／预览请求及文档渲染轮次保护异步加载，旧结果不会启用其他订单或较新的预览。品牌数据不写入审图JSON、审计或SW请求。

## 完整参数与计算结果

确认单将基础参数和高级参数合并为“输入参数”，先列原基础参数，再按现有顺序接上符合显示条件的高级参数，使用一张连续表格，不保留两类子标题。左侧打印选择同样合并，行ID保持不变，刷新预览保留已有勾选状态。审图编辑页面继续保留基础／高级布局。

参数来自当前压缩弹簧模板及兼容返回字段。普通订单与多规格子记录共用高级参数显示规则，预览、选择打印项目与PDF同步：

| 高级字段 | 显示规则 |
|---|---|
| 支承圈数（单端）、节距、刚度、垂直度 | 固定显示；缺值时可在参数区填写，确认单显示“待补充” |
| 直线度、永久变形限值、端圈数、弹体长度、受控直径 | 缺值时隐藏；有识别值、人工值、正式计算值、公差或待核对输入时显示 |
| 直径、自由高度、载荷、刚度的专项精度等级 | 参数区及确认单隐藏，保留原数据、确认及标准计算优先级 |

高级区默认折叠；来源、证据、默认来源标记、未采用建议不能制造空行。兼容字段仅在有实际内容时展示。数字0、非法值及失效值仍供核对。清空按需字段后，离开整行才收起，在数值框和公差框之间切换不会移除当前行。隐藏不删除字段、不触发保存；批量确认不处理隐藏项或空的可选高级项。

按需字段的空行不单独生成客户补充问题，实际风险、冲突及有效建议继续展示；专项精度不生成独立确认事项。打印范围不改变生图必填项或校验规则。受控直径、旋向等枚举使用中文显示。

计算仅使用现有 `CompressionDesignChecks.calculate` 的结果：旋绕比、细长比、理论刚度、曲度系数、螺旋角、展开长度、单件重量、压并应力、压并高度及每个载荷点的工作应力。计算项“压并高度”沿用名义压并高度的计算值，并注明估算；“压并高度上限参考”和“应力采用高度”仅保留在内部计算中，不列入确认单、打印选择或对应的补充问题。

每项均可独立选择打印并留客户确认框，与参数表中的当前刚度、图纸／人工压并高度分别展示。估算注明估算，长公式和内部输入JSON不打印。无法计算显示原因，不适用或无需计算的项明确说明，不补0或复用过期结果。公开数值沿用既有显示精度，极小非零数不被格式化为0。此处仅调整确认单展示，不改变原计算器、应力采用值、参数确认或SW请求。

问题与建议按同一字段合并，保留不同建议方案；仅有内部待确认状态的正常行不重复列为问题。缺失、冲突、失效、风险和无法计算仍给出说明。客户纸面反馈后由工作人员在原参数区回填、核对和保存。

## 数据与保护

`parameter-confirmation-sheet.js` 管理独立预览和打印文档，预览与打印共用HTML及A4样式。所有派生计算只在审图副本执行；复用现有只读 `POST /api/reviews/reasonableness` 取得最新确定性诊断，不调用Qwen、RAGFlow或SW。诊断暂不可用时，仍可打印参数及安全的本地结果，并注明检查需重新核对。

预览输入包含订单、用户／服务范围、导航序号、编辑计数和内部审图修订。材料目录版本、状态和属性也纳入计算指纹，并在开始构建时复制；参数或计算依据变化后停用旧预览打印。等待保存及诊断时切换订单会关闭旧预览，晚到响应丢弃。保存重试成功后才能重新预览。勾选、打开打印窗口及取消打印均不确认参数、不采用建议，不写入审图审计或修改精度、生图状态。打印关闭事件不代表打印成功。

文本按HTML转义，预览iframe禁用脚本，只允许父页面访问和浏览器打印。无需新增后端接口、数据库字段或迁移。
